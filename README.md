# Car Repair Shops Data Scraper

## Project Overview

This project focuses on extracting car repair shop information from Google Maps using the Instant Data Scraper Chrome extension.

The collected data is exported into Excel and CSV files for organization and analysis.

## Tools Used

- Google Maps
- Instant Data Scraper
- Microsoft Excel
- CSV

## Data Fields

- Car Repair Shop Name
- Address
- Phone Number
- Rating
- Website URL (if available)

## Features

- Extracts visible car repair shop information
- Collects available contact details
- Organizes data into structured tables
- Exports results to Excel and CSV

## Project Workflow

1. Open Google Maps.
2. Search for car repair shops.
3. Use Instant Data Scraper to extract available information.
4. Export the collected data.
5. Organize the results in Excel.
